Digital Health Records
======================
A simple web app to store patient details and medical history.

How to run
1. Unzip this folder.
2. Double-click index.html to open it in a browser (Chrome, Edge, Firefox).

Files
- index.html : page structure
- style.css  : design (light/dark mode)
- script.js  : logic (add/search/delete patients, visit records, JSON export)

Data is saved in the browser's localStorage (no server or database needed).
